# Malaysian Food Dataset — Nasi Lemak

Датасет фотографий малайзийского блюда **Nasi lemak** (рис на кокосовом молоке с самбалом, жареными анчоусами, арахисом, яйцом и огурцом).

- **Класс:** `nasi_lemak`
- **Фото:** 71 шт., JPEG, ширина ~960 px
- **Проверка:** каждое фото просмотрено вручную; убраны логотипы, упаковки, вывески, фото с водяными знаками, коллажи и почти одинаковые кадры

## Источник и лицензии

Все фото взяты с [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Nasi_lemak) и распространяются под свободными лицензиями (CC0, Public domain, CC BY, CC BY-SA, GFDL). Автор, ссылка на оригинал и лицензия для каждого файла указаны в `CREDITS.csv`. При использовании фото под CC BY / CC BY-SA нужно указывать автора и лицензию.
